# Final boss picture (optional)

Put **your own** picture here as `body.png` (a cut-out with a transparent background, about 256 px tall, feet at the bottom).
Optional: `portrait.png` (128x128 face for the boss bar). Then open the project in Godot once so it imports.

Set the name and the line she says in `scripts/slime_king.gd` (`FINAL_BOSS_NAME`, `FINAL_BOSS_LINE`).

If `body.png` exists, beating the Hamster Godfather starts a second fight against this boss (14 HP, same moves).
If it doesn't exist, the game ends after the Godfather like before.
Add the picture's source/artist to CREDITS.md.
